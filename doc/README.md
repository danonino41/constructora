## Cómo mantenerlo

- Cada vez que el CEO envíe nuevas observaciones, se agregan en `01-observaciones-ceo-ux-ui.md` (fechadas).
- Cada vez que un componente/sección de la web cambie por indicación, se actualiza el registro en `02-funciones-principales.md`.
- Estado de implementación se indica con: `[Pendiente]`, `[En proceso]` o `[Hecho]`.
