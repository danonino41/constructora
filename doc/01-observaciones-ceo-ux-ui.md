# Observaciones del CEO – Evaluación UX/UI

> Fuente: correo del CEO (reunión de equipo). Fecha: pendiente de registrar.

La presencia digital de Consorcio Constructor (sitio web y redes sociales) debe orientarse a facilitar la experiencia del usuario y reflejar la identidad de marca. El visitante —cliente final o promotor inmobiliario— debe encontrar fácilmente:

1. Qué programas ofrece (Techo Propio, Bono de Reforzamiento, Nuevo Crédito MiVivienda).
2. Cómo funciona cada trámite.
3. Contacto para asesoría.

## Requerimientos de UX/UI

### Navegación clara y sencilla
- [ ] Menú destacado con las tres áreas principales: **Techo Propio**, **Bono Reforzamiento**, **Crédito MiVivienda**.
- [ ] Apartado *"¿Qué es Techo Propio?"* con lenguaje sencillo (inspirado en fuentes oficiales): requisitos y beneficios.
- [ ] Cada sección guía al usuario paso a paso, con enlaces a formularios o información oficial (similar al portal de Fondo MiVivienda).
- [ ] No usar logotipos oficiales; solo referencia/nombre de los programas.

### Diseño accesible y coherente
- [ ] Paleta de colores institucional y tipografía legible (tipo Myriad Pro bold/regular, textos en #4a4a49).
- [ ] Iconos o imágenes representativas (p. ej. casa en construcción) que enfaticen *"construcción propia"*.
- [ ] Contraste suficiente para lectura (accesibilidad) y tamaño de fuente cómodo.
- [ ] Sitio responsivo para móviles (la mayoría accede desde celular).

### Contenido enfocado en el usuario
- [ ] Bloques de texto cortos (3–5 líneas) y listas.
- [ ] Bullet points para pasos del proceso, requisitos y beneficios.
- [ ] Preguntas frecuentes (FAQs) sobre los programas.
- [ ] Enlaces a recursos oficiales (Fondo MiVivienda o reglamentos) para transparencia.

### Llamados a la acción claros (CTAs)
- [ ] Botones visibles: *"Solicita información"*, *"Regístrate aquí"*, *"Descarga requisitos"*.
- [ ] Flujo lógico guiado: de *"Conoce el Programa Techo Propio"* a *"Cotiza tu Crédito MiVivienda"*.

### Velocidad y desempeño
- [ ] Carga rápida de la página.
- [ ] Optimizar imágenes y evitar animaciones complejas.

### Integración de redes sociales
- [x] Enlace directo a Facebook (y otras redes) — implementado en navbar, footer y sección Galería.
- [ ] Contemplar feed o testimonios reales para reforzar confianza.

## Estructura lógica del sitio (meta)
`inicio → programas → registro → contacto`

## Nota final del CEO
El sitio debe verse intuitivo, con estructura lógica y diseño alineado a la identidad de marca. La información clave (programas del MVCS, requisitos, beneficios) debe estar fácilmente accesible, reduciendo la carga cognitiva del visitante. Un sitio bien diseñado refuerza la percepción de profesionalismo y confiabilidad.
